# Changelog

All notable changes to this package are documented here.

## [1.0.0] - 2026-08-10

### Added

* Initial Transition System package.
* Centralized transition management.
* Fade transitions.
* Slide transitions.
* Grow transitions.
* Mask transitions.
* Animation-based transitions.
* Configurable transition assets and presets.
* Plug-and-play `TransitionManager` prefab.
* Example scene provided as a package sample.
* Singleton package dependency.
